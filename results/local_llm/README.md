# 무료 로컬 LLM 실험 자료

유료 API 없이 Ollama의 로컬 모델로 생성한 실제 응답과 비교 결과입니다. 사용한 모델은 `qwen2.5:1.5b`, `llama3.2:3b`입니다. 모델 가중치는 이 저장소에 포함하지 않습니다.

[전체 보고서](../../docs/local_llm_research.md)와 [고정 실험 규칙](../../benchmarks/local_protocol.json)을 함께 확인하세요.

| 경로 | 내용 |
|---|---|
| `*_validation_v2/` | 출력 형식을 확인한 검증용 응답, 모델당 20개 |
| `*_test_v2/` | 최종 평가용 실제 안내, 모델당 120개·지도 60개 |
| `*_transpose_v2/`, `*_scale2_v2/` | 변형한 입력에서 새로 생성한 안내, 모델당 각각 10개 |
| `*_evaluation_v2/` | 최종 비교 측정값·신뢰구간·경로 유효성·메모리 할당·안내 오류 |
| `aggregate_v2.json`, `comparison_v2.png` | 최종 집계와 그래프 |
| 이름에 `_v2`가 없는 폴더 | 초기 v1 진단 결과; 최종 표와 합산하지 않음 |
| `llama_test/interrupted.json` | v1 검증 실패 후 중단한 불완전 평가 기록 |
| `generator_v1.py.txt` | 초기 v1 생성기 소스 보존본 |

생성 폴더의 `plan.json`에는 첫 응답 생성 전에 고정한 입력·모델 해시·옵션·프롬프트 규칙이 있습니다. `responses.jsonl`은 원문 응답과 생성 메타데이터, `waypoints.json`은 비교 실행용 캐시, `generation_summary.json`은 응답 수·형식 오류·소요 시간 요약입니다. 중단한 v1 실행에는 완료 캐시와 요약이 없고, 원문 응답과 중단 이유만 있습니다.

비교 폴더의 `raw.csv`는 탐색별 측정값, `summary.json`은 동일 입력의 비율, `bootstrap.json`은 지도 단위 95% 신뢰구간입니다. `quality.json`은 모델 안내의 오류, `allocations.json`은 탐색기의 Python 할당 최대값입니다. `traces.json.gz`는 경로·람다 변화 기록이며 압축 전후 해시는 `metadata.json`에 있습니다.

형식 오류는 빈 안내로 처리했고 실패한 모델 답변을 정답으로 보정하지 않았습니다. 모델 안내 생성 성공률과 탐색 경로 성공률은 구분해야 합니다. Storage는 상태 수이며 전체 시스템 메모리 사용량과 다릅니다. 반복 실행하면 시간이나 모델 출력이 달라질 수 있으므로, 비교 재현에는 저장된 캐시를 사용하세요.

이 실험은 양자화한 소형 모델과 추가 출력 지시를 사용합니다. 원 논문 모델의 정확한 재현이나 논문 대비 성능 우위를 입증하지 않습니다. API 사용료는 0달러이며 로컬 컴퓨터의 시간·전력·저장 공간을 사용했습니다.
