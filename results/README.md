# Experiment artifacts

All model-free benchmark results are retained for inspection. These are saved
experimental observations, not regenerated by opening this repository.

| Directory | Role |
|---|---|
| `train_tuning` | First train-only parameter sweep; historical prototype results |
| `train_refined` | Second train-only sweep; selected default comes from this run |
| `validation` | 20 independent maps; configuration validation |
| `test` | Final 60 held-out maps, 600 queries, seven advice conditions |
| `transfer` | Transpose, 2x scale, and weighted-edge checks on validation maps |
| `assistant_pilot` | 12 illustrative assistant-authored waypoint cases |
| `smoke` | Initial two-map sanity run; not used for final conclusions |

Each main run includes `metadata.json`, `raw.csv`, `summary.json`, and a cached
`waypoints.json`. The final test also includes `aggregate.json` and the plotted
`comparison.png`. Metadata records the configurations, map IDs, guidance source,
dataset digest, and (for final runs) source digests. Historical source digests
describe the code at the time of each run; subsequent changes can differ.

Large path and lambda-history records are stored losslessly as `traces.json.gz`.
`archive_manifest.json` records compressed and uncompressed SHA256 digests.
To unpack a record locally:

```bash
python -c 'import gzip,pathlib; p=pathlib.Path("results/test/traces.json.gz"); p.with_suffix("").write_bytes(gzip.decompress(p.read_bytes()))'
```

Regenerating a benchmark can update timings; graph preparation and LLM generation
are excluded from planner-only timings. `--save-paths` writes `traces.json`, which
is ignored by Git until compressed. The report generator reads the CSV/JSON
summaries and does not require trace decompression.

Read [the full report](../docs/adaptive_lambda_research.md) before comparing these
results with the paper. In particular, upstream Storage includes infinite-cost
entries, whereas the new engine counts finite discovered states. The controlled
fixed-lambda baseline separates shared implementation changes from adaptive
weighting.
